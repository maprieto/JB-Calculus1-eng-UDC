# JB-Calculus1-eng-UDC

This repository contains a Jupyter Book.

GitHub Pages deployment is automated with the workflow in `.github/workflows/deploy-book.yml`.
Each push to `main` builds the book and publishes `_build/html` to GitHub Pages.
If the repository has never published with GitHub Pages before, enable GitHub Pages with the **GitHub Actions** source in the repository settings once so the workflow can create deployments.
