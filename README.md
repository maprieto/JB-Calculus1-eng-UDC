# Course: Calculus, [Degree in Computer Engineering, Faculty of Computer Science, UDC](https://fic.udc.es)
These Jupyter files correspond to the scripts for the tutored practice sessions of the course
**Calculus**, taught in the Grade of Computer Engineering, Faculty of Computer Science, at the University of A Coruña in the 2026–2027 academic year.
The Jupyter notebooks may be used, shared, and modified free of charge.
Please refer to the license and copyright information described below.

## Viewing and Running
Copies of these Jupyter notebooks can be run locally in your laptops or computer desktops with a Jupyter and Python installation
They can also be run using the Google Colab cloud service: [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/maprieto/JB-Calculus1-eng-UDC/)

For the best experience, it is recommended to download or clone (using the 'clone' option) the full project from GitHub in order to use these files in a local Jupyter environment.

## Getting Started
Each Jupyter Notebook explores a topic, with a small set of exercises
to be completed by students at the end of the practical session.
