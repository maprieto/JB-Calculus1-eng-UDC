# Basic definitions

````{prf:definition} Real function of a real variable
:label: def_funcion
:nonumber: 

Let $\mathrm{A}\subset\mathbb{R}$. We define a real function of a real variable
as a map that sends each point of $\mathrm{A}$ to a unique point of $\mathbb{R}$.

$$
\begin{array}{ccccc}
f&:&\mathrm{A}\subset\mathbb{R}&\rightarrow&\mathbb{R} \\
&&x\in\mathrm{A}&\rightarrow&f(x).
\end{array}
$$
````

````{prf:definition}  
:label: def_func_varias
:nonumber: 

Let $f:\mathrm{A}\subset\mathbb{R}\rightarrow\mathbb{R}$ be a function. Then:
1. The **domain of $f$** is the set $\mathrm{A}$.
2. The **image of $f$** is the set
  $ \displaystyle
  \mathrm{im}\, f=\left\{y\in\mathbb{R}: \exists x\in \mathrm{dom}\, f \text{ such that }f(x)=y\right\}$.
3. We will say that $f$ is **bounded** on $\mathrm{A}$ (respectively, bounded above or below) if the set $\mathrm{im}\, f$ is bounded (respectively, bounded above or below).
4. Let $\mathrm{B}\subset\mathrm{A}$. We will say that $f$ is **increasing** on $\mathrm{B}$ if
$ \displaystyle
  \forall x_1, x_2\in\mathrm{B} / x_1<x_2\Rightarrow f(x_1)\leq f(x_2)$.
5. Let $\mathrm{B}\subset\mathrm{A}$. We will say that $f$ is **strictly increasing** on $\mathrm{B}$ if
  $ \displaystyle
  \forall x_1, x_2\in\mathrm{B} / x_1<x_2\Rightarrow f(x_1)< f(x_2)$.
6. Let $\mathrm{B}\subset\mathrm{A}$. We will say that $f$ is **decreasing** on $\mathrm{B}$ if
  $ \displaystyle
  \forall x_1, x_2\in\mathrm{B} / x_1<x_2\Rightarrow f(x_1)\geq f(x_2)$.
7. Let $\mathrm{B}\subset\mathrm{A}$. We will say that $f$ is **strictly decreasing** on $\mathrm{B}$ if
  $ \displaystyle
  \forall x_1, x_2\in\mathrm{B} / x_1<x_2\Rightarrow f(x_1)> f(x_2)$.
````

## Even/odd symmetries

````{prf:definition} Symmetries
:label: def_simetrias
:nonumber: 

Let $f:\mathbb{R}\rightarrow\mathbb{R}$. We will say that $f$ is
* **Even** if $f(x)=f(-x)$, $\forall x\in\mathbb{R}$.
* **Odd** if $f(x)=-f(-x)$, $\forall x\in\mathbb{R}$.
````

The name comes from the basic monomials. Monomials with an even exponent ($x^2$, $x^4$, $x^6$ ,...) have even symmetry, and monomials with an odd exponent ($x$, $x^3$, $x^5$ ,...) have odd symmetry.

## Periodic function

````{prf:definition} Periodic function
:label: def_funcion
:nonumber: 

Let $f:\mathbb{R}\rightarrow\mathbb{R}$. We will say that $f$ is periodic, with period $T$, if

$$
f(x)=f(x+T),\qquad\forall x\in\mathbb{R}.
$$
````

The most classical example of periodic functions is the trigonometric functions.
For example, the sine function is periodic with period $2\pi$, as we will show in the next section.

If we know that a function has period $T$, it is enough to
represent it on $[0,T]$. After that it repeats.

## Composition of functions

````{prf:definition} Composition of functions
:label: def_composicion
:nonumber: 

Let $f:\mathrm{A}\subset\mathbb{R}\rightarrow\mathbb{R}$,
$g:\mathrm{B}\subset\mathbb{R}\rightarrow\mathbb{R}$, with
$f(\mathrm{A})\subset\mathrm{B}$. We define the composite function $g\circ f$ (read as *f
composed with g*) to be the function

$$
\begin{aligned}
g\circ f:\;  & \mathrm{A}\subset \mathbb{R} & \rightarrow & \; \mathbb{R} \\
 & x\in\mathrm{A} & \rightarrow & \; (g\circ f)(x):=g\left(f(x)\right).
\end{aligned}
$$
````

To practice the previous definition, we propose the following **exercises**:

1. Compose, in the two possible ways, the functions $f(x)=e^{x^2-1}$ and $g(x)=\sin(2x)+\cos(x)$.

    **Solution:**
    $\displaystyle\left(g\circ f\right)(x)=g\left(f(x)\right) =
    g\left(e^{x^2-1}\right)= \sin\left(2e^{x^2-1}\right)
    +\cos\left(e^{x^2-1}\right)$.

    Note that composition is not a commutative operation. In this same example, if we compose in the reverse order,

    $\displaystyle
    \left(f\circ g\right)(x) = f\left(g(x)\right) =
    f\left(\sin(2x)+\cos(x)\right) =
    e^{\left(\sin(2x)+\cos(x)\right)^2-1}$.

2. Compose, in the two possible ways, the functions $f(x)=\frac{x^4+x^2}{5}$, $g(x)=\ln(x+2)$.

## Inverse function

````{prf:definition} Inverse function
:label: def_inversa
:nonumber: 

Let $f:\mathrm{A}\subset\mathbb{R}\rightarrow\mathbb{R}$ be an injective function (that is, if $x\not= y$,
$f(x)\not= f(y)$). Then there exists a unique function $h:\mathrm{im}\, f\rightarrow\mathbb{R}$ such that
$h\left(f(x)\right)=x$, $\forall x\in\mathrm{A}$.

This function is called the **inverse of $f$** and is usually denoted by $f^{-1}$.
````

That is, according to the definition of inverse, we have $f^{-1}\circ f=\mathrm{Id}$.
Moreover, in this case composition is commutative, that is, $f\circ f^{-1}=\mathrm{Id}$ (the function $\mathrm{Id}$ is the identity function, that is,
$\mathrm{Id}(x)=x$, $\forall x\in\mathbb{R}$).

<img src="../../images/cap3_function_inverse.png" width="200"/>

**One must not think that $\boldsymbol{f^{-1}=\frac{1}{f}}$!**

The practical way to compute an inverse function is to solve for $x$ in terms of $y$ (that is, of $f(x)$) and swap their roles. We see an example in the following exercise.

**Exercises**

1. Compute the inverse of the function $\displaystyle f(x)=\frac{e^x}{1+e^x}$.

    **Solution:**

    $$\frac{e^x}{1+e^x}=y\Rightarrow e^x=y+ye^x\Rightarrow e^x(1-y)=y
    \Rightarrow e^x=\frac{y}{1-y}\Rightarrow x=\ln\left(\frac{y}{1-y}\right).
    $$

    Therefore the inverse function is $\displaystyle f^{-1}(x)=\ln\left(\frac{x}{1-x}\right)$.

    It remains as an exercise for the reader to check that indeed $f^{-1}\circ f=f\circ f^{-1}=\mathrm{Id}$.

    **Note:** For us, both $\log$ and $\mathrm{ln}$ represent the natural logarithm.

2. Compute the inverse of the function $\displaystyle f(x)=\frac{2}{1+e^x}$.
