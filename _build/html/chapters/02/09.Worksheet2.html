Worksheet 2: Limits, continuity, Lagrange, and bisection

2.9. Worksheet 2: Limits, continuity, Lagrange, and bisection#

  1. Compute, if possible,

    a. \(\displaystyle{\lim_{x\rightarrow 0}{\frac{|2x-1|-|2x+1|}{x}}}\),

    b. \(\displaystyle{\lim_{x\rightarrow 0}{\frac{\sqrt{x^2+4}-2}{x^2}}}\),

    c. \(\displaystyle{\lim_{x\rightarrow 0}{\left (\frac{1}{x}-\frac{1}{|x|}\right)}}\).

  2. Compute, if possible, the following limits:

    \[\begin{split} \begin{array}{lllll} %\text{$(a)$ } \displaystyle{\lim_{x\rightarrow -\infty} e^x} &\qquad %\text{$(b)$ } \displaystyle{\lim_{x\rightarrow 0} e^x} &\qquad %\text{$(c)$ } \displaystyle{\lim_{x\rightarrow +\infty} e^x} &\qquad \text{$a)$ } \displaystyle{\lim_{x\rightarrow -\infty} \sqrt[3]{x}} & \qquad \text{$b)$ } \displaystyle{\lim_{x\rightarrow +\infty} \sqrt{x}} &\qquad \text{$c)$ } \displaystyle{\lim_{x\rightarrow 0^+} \sqrt{x}} &\qquad \text{$d)$ } \displaystyle{\lim_{x\rightarrow -\infty} \sqrt{x}} \\ \\ \text{$e)$ } \displaystyle{\lim_{x\rightarrow +\infty} \dfrac{1}{\sqrt{x}}} & \qquad \text{$f)$ } \displaystyle{\lim_{x\rightarrow 0^+} \dfrac{1}{\sqrt{x}} } &\qquad %\text{$j)$ } \displaystyle{\lim_{x\rightarrow +\infty} x^2} &\qquad \text{$g)$ } \displaystyle{\lim_{x\rightarrow -\infty} x^2 } &\qquad \text{$h)$ } \displaystyle{\lim_{x\rightarrow +\infty} \left( x^3 - 5x^2 + 8 \right)} \end{array} \end{split}\]

  3. The value, in euros, of a car \(x\) years after it was bought new is given by the function

    \[ v(x)=2000+\frac{60000}{4^{0.25 x}}. \]

    The residual value of the car is its limiting value when the number of years increases indefinitely.

    a. What was the purchase price of the new vehicle?

    b. What will its residual value be?

    c. After how many years will its value differ from the residual value by less than 1000 euros?

  4. Draw, with Sympy, the graph of the curve \(y=\sqrt{x^2+1}-x\).

    Using pencil and paper, and checking the results on the computer, determine whether this graph has any asymptotes and, if so, obtain their equations.

  5. Compute the asymptotes of the following functions:

    a. \(\displaystyle{v_{1}(x)= \frac{3x^2-2}{4x^2 +1}}\),

    b. \(\displaystyle{h(t)= \frac{t^2+2}{t -2}}\),

    c. \(\displaystyle{v_{2}(x)= \frac{3x^2-2}{4x^2 -1}}\),

    d. \(\displaystyle{f(x)=x^\frac{|x|}{x} + \frac{1}{x}}\).

  6. Consider the function \(f\), given by \(f(x) = \ln(x)\).

    a. What is its domain? What is its image?

    b. What are the values of \(\displaystyle{\lim_{x\rightarrow +\infty}\ln(x)} \,\,\) and \(\displaystyle{\lim_{x\rightarrow 0^+}\ln (x)}\)?

    c. Does \(\displaystyle{\lim_{x\rightarrow -\infty}\ln(x)}\) exist? Why?

    d. Does \(f\) have a vertical asymptote? If so, what is its equation?

    e. Draw the graph of \(f\).

    f. Using the relationship between the graph of a function and the graph of its inverse, sketch the graph of \(g(x)=e^x\). From observing this graph, deduce the existence of a horizontal asymptote.

  7. Let us review the arctangent function (\(\arctan\)):

    a. What is the domain of the function \(f(x)=\arctan(x)\)? And its image?

    b. Is it true that \(\dfrac{1}{\tan(x)} = \arctan(x)\)? Why?

    c. Which angles have tangent equal to \(1\)?

    d. Is it correct to say that \(\arctan (1)=\dfrac{\pi}{4}+k\pi\), \(\,k \in \mathbb{Z}\)? Why?

  8. If the length of an animal \(t\) days after birth is

    \[ \ell(t)= \frac{300}{1+9\left(0.8\right)^t} \]

    how long was it at birth? Obtain an upper bound for its maximum size.

  9. Choose the correct option:

    To approximate the value of the solution of the equation \(x^3+2=0\) with an error smaller than \(0.30\) using the bisection algorithm on the interval \([-2,\,2]\):

    a. we must perform four iterations and the first three are \(x_1=0\), \(x_2=-1\) and \(x_3=-3/2\)

    b. we must perform four iterations and the first three are \(x_1=0\), \(x_2=-1\) and \(x_3=-1/2\)

    c. we must perform three iterations and the first two are \(x_1=0\) and \(x_2=-1\)

    d. we must perform three iterations and the first two are \(x_1=0\) and \(x_2=1\).

  10. Where is the function \(f\) given by \(f(x)=\displaystyle{\frac{e^x+\ln(2x)}{x^2-3}}\) continuous?

  11. Choose the correct option:

    The function \(f : \mathbb{R} \longrightarrow \mathbb{R}\) given by:

    \[\begin{split} f(x) = \begin{cases} \sqrt{{x}^{2}-1} \,\,\,\, \qquad\, \text{ if } x \in (-\infty,-1] \\ {x}^{2}+2x+1 \qquad \text{if } x \in (-1,10] \\ \frac{121}{10}x \qquad\, \, \, \, \qquad \text{ if } x \in (10,+\infty) \end{cases} \end{split}\]

    a. It is not continuous at \(x=-1\)

    b. It is continuous on \((-\infty,\infty)\)

    c. It is not continuous at \(x=10\)

    d. It is not continuous at \(x=0\)

  12. Study the continuity at \(x=0\) of the function \(f : \mathbb{R} \longrightarrow \mathbb{R}\) given by:

    \[\begin{split} f(x) = \begin{cases} x e^{-x} \, \qquad\,\quad \text{if } x < 0 \\ 1 \qquad \qquad \,\,\,\,\,\, \text{if } x = 0 \\ \sqrt{x^2+1} \qquad \text{if } x > 0 \end{cases} \end{split}\]

  13. If \(a>1\), study the continuity of the function \(f : \mathbb{R} \longrightarrow \mathbb{R}\) given by:

    \[\begin{split} f(x) = \begin{cases} {x}^{2} {\cos^2\left(\frac{1}{x}\right)} \qquad\,\quad \text{if } x < 0 \\ 0 \qquad \qquad \,\,\,\,\,\,\,\quad \text{ if } x = 0 \\ \dfrac{x {a}^{x}-x} {\sqrt{1+x}-1} \qquad \text{if } x > 0 \end{cases} \end{split}\]

  14. Prove that the equation \(x + \sin (x) = \dfrac{1}{\sqrt{x}+3}\) has at least one root in \([0,\pi]\).

  15. Justify the existence of a solution of the equation \(e^x+4x=0\) on the interval \([-1, 0]\). Determine the number of iterations needed to approximate the solution by the bisection method with an error smaller than one hundredth, and compute the first three iterations.

  16. Let the function \(f\) be given by:

    \[\begin{split} f(x) = \begin{cases} \displaystyle{\frac{x^2}{1+e^{1/x}} - 1} & \quad \text{if } x \neq 0 \\ \\ - 1 & \quad \text{if } x =0. \end{cases} \end{split}\]

    a. Study the continuity of \(f\) on \(\mathbb{R}\).

    b. Justify the existence of a root of \(f\) on the interval \([0,\, 2].\)

    c. Compute the first two iterates of the bisection algorithm, applied to \(f\) on the interval \([0,\,2],\) to approximate the root referred to in the previous part.

  17. Pointwise measurements have determined that an unknown function \(f\) passes through \((-2, -16)\), \((0, 0)\), \((1, -1)\) and \((3, 9)\). Compute, using divided differences, a polynomial approximation of \(f\). Use this polynomial to approximate \(f(2)\).

  18. Compute the third-order Lagrange interpolation polynomial corresponding to \(f(x) = 2^{x+1}-5\) at the points \(x_0 = 1\), \(x_1 = 2\), \(x_2 = 3\) and \(x_3 = 4\). Using the previous calculations, compute an approximation of the number \(r = 4 \sqrt{2}-5\) and an approximation of the root of the equation \(\log_2 (y+5) = 3.5\).

  19. Use Newton’s formula to obtain the interpolation polynomial of the function \(f(x)=\sin(x)\) relative to the points \(\displaystyle{ 0, \frac{\pi}{2}, \pi}\) and \(\displaystyle{\frac{3\pi}{2} }\). Use it to approximate the sine of \(\displaystyle{\frac{\pi}{4}}\).

  20. Consider the following table of values, corresponding to measurements of a function \(f\):

    \(x_{i}\)

    -1

    0

    1

    3

    4

    \(f(x_{i})\)

    6

    3

    6

    38

    77

    a. Compute the second-order Lagrange interpolation polynomial \(p\) corresponding to \(f\) at the nodes \(\{ 1,3,4 \}\).

    b. Compute the second-order Lagrange interpolation polynomial \(q\) corresponding to \(f\) at the nodes \(\{ -1,0,1 \}\).

    c. Approximate \(f(0.25)\) and \(f(2)\).

  21. Choose the correct option:

    If we use the Lagrange polynomial interpolating the nodes \((-2,-8)\), \((-1, 0)\) and \((1, 4)\) to approximate the value at \(x=0\), we obtain:

    a. -4

    b. 0

    c. 4

    d. with the Lagrange polynomial interpolating those nodes, it is not possible to approximate the value at \(x=2\).

  22. Choose the correct option:

    The coefficient of degree \(1\) of the Lagrange polynomial interpolating the data in the following table

    \(x_{i}\)

    -2

    -1

    1

    0

    \(y_{i}\)

    4

    4

    10

    6

    a. is 0

    b. is 1

    c. is 3

    d. that polynomial does not exist.

  23. Reason out whether the following statements are true or false:

    a. Let \(f:[0,2]\rightarrow \mathbb{R}\) be continuous and such that \(f(1)=0\). Then, by Bolzano’s theorem, it must hold that \(f(0)f(2)<0\).

    b. There exists a point \(x \in (0,1)\) such that \(\displaystyle{e^{x}=\frac{3}{2}}\).

    c. The function \(g\) given by \(\,g(x)=\dfrac{16}{{a}^2+2abx+{b}^2{x}^2}\,\), where \(a\) and \(b\) are two nonzero real numbers, is continuous whenever \(x\) differs from \(\,\frac{-a}{b}\).

    d. The function \(h\) given by \(\displaystyle{ h(x)=\frac{1}{1+e^{-1/x}} }\) has no limit at \(0\).

    e. The graph of the function \(\dfrac{{x}^{3}}{{(x+1)}^2}\) intersects its oblique asymptote at a point whose abscissa lies between \(-1\) and \(0\).

    f. Every polynomial \(p\) satisfies \(p(x+y)=p(x) + p(y)\).
