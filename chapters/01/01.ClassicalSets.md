# Classical sets of numbers

## Natural numbers, $\mathbb{N}$

The smallest set of numbers is the one formed by the *natural numbers*,

$$\mathbb{N}=\left\{1,2,3,4,...\right\}.$$

There are different opinions about whether $0$ should be included in this set or not, although this is
indifferent for our objective.
We, as we have already written, consider that $0$ is not in $\mathbb{N}$.

## Integers, $\mathbb{Z}$

When the naturals proved insufficient for some simple operations
(such as subtraction), the set was expanded and the
*integers* emerged,

$$\mathbb{Z}=\left\{...,-3,-2,-1,0,1,2,3,...\right\}.$$

Given their respective definitions, it is evident that $\mathbb{N}\subset\mathbb{Z}$.

## Rational numbers, $\mathbb{Q}$

When division was defined and studied, it became clear that integers were not
sufficient, so the set of *rational numbers*,
$\mathbb{Q}$, was born. This set is formed by fractions, $\frac{p}{q}$, where $p$
is an integer and $q$ is natural (since we defined $\mathbb{N}$ without including $0$, we thus avoid
the always awkward division by this number).

An approximate (and therefore, always less precise) way of representing the rationals is in
decimal format: $\alpha_0\, .a_1 a_2... a_n...$, where $\alpha_0\in\mathbb{Z}$ and
$a_i\in\mathbb{Z}$ with $0\leq a_i\leq 9$, for any index $i$.

If we think that $p=\frac{p}{1}$, $\forall p\in\mathbb{Z}$, it turns out that $\mathbb{Z}\subset\mathbb{Q}$.

## Real numbers, $\mathbb{R}$

For many centuries it was thought that rational numbers were sufficient,
despite evidence showing the contrary. Finally, the Greeks had to
surrender to evidence showing that, for example, the length of the hypotenuse of a
right triangle with both legs of unit length cannot be represented
as a fraction. That is, $\sqrt{2}\not\in\mathbb{Q}$.

It is an example of an **irrational number**, as are $\pi$, $e$, $\sqrt{3}$,
*etc.*. **Real numbers**, $\mathbb{R}$, appear, grouping together both rationals and
irrationals.

There are two very important properties of real numbers that we would like to highlight
here:

* **Archimedean property**: Given two real numbers, $a,b\in\mathbb{R}$, such that $0<a<b$, then $\exists n\in\mathbb{N}$ such that $b<na$.
For example, if $a=0.1$ and $b=6000.38$, we can take $n=100000$ to obtain that $6000.38<100000*0.1$.
* **Property. Density of $\mathbb{Q}$ in $\mathbb{R}$**: Given two real numbers $a$ and $b$, with $a<b$, there exists $q\in\mathbb{Q}$ such that $a<q<b$.

These properties deserve a brief explanation:

* The Archimedean property tells us that given any real number, we can always find a larger one and, by multiplying the reasoning by $-1$, we can also find a smaller one. That is, $\mathbb{R}$ is an infinite set both upwards and downwards.
* The density property indicates that given any two real numbers (and distinct, of course), there will always be another real number between them. And another two real numbers between these three and... That is, the set of real numbers is continuous.

With this we now have the theoretical justification we need to introduce the most common way
to represent real numbers: on an infinite line. Given a point on
the line, $a$, which we can identify with a real number, to its right will be the
real numbers greater than $a$ and to its left the lesser ones. Thanks to the density property, the line has no
*holes* (that is, it is continuous).

Let us look at some important definitions related to the bounding of subsets of $\mathbb{R}$.

```{prf:definition}
:label: def_cotas
:nonumber: 

Let $\mathrm{A}$ be a non-empty subset of $\mathbb{R}$ ($\mathrm{A}\subset\mathbb{R}$, $\mathrm{A}\not=\emptyset$).

  1. We say that $M\in\mathbb{R}$ is an **upper bound** of $\mathrm{A}$ if 
      
      \begin{equation*}
        x\leq M,\qquad\forall x\in\mathrm{A}.
      \end{equation*}
      
      If the set $\mathrm{A}$ admits any upper bound we say it is **bounded 
      above**.
  2. We say that $m\in\mathbb{R}$ is a **lower bound** of $\mathrm{A}$ if 
      
      \begin{equation*}
        m\leq x,\qquad\forall x\in\mathrm{A}.
      \end{equation*}
      
      If the set $\mathrm{A}$ admits any lower bound we say it is **bounded 
      below**.
  3. If $\mathrm{A}$ is bounded both above and below we will simply say it is 
      **bounded**.


```
